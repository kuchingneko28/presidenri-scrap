## Phase 3: DRY — Extract Duplicated Code

### 3a. Centralize shutdown pattern
- Add `registerShutdown(app, logger)` helper in `services/ExitHandler.ts` (or a new `utils/shutdown.ts`)
- All 7 command files call it instead of `app.shutdown(); process.exit(0)`

### 3b. Centralize post-scrape completion in BaseScraper
- Add `completeScrape()` method to `BaseScraper`
- Handles: state="downloading", updateStats, conditional waitForDownloads, stopSpinner, success log
- All 3 scrapers call `this.completeScrape()` instead of duplicating 5 lines

### 3c. Consolidate `isShuttingDown` pattern
- Move `isShuttingDown` + `setShuttingDown()` + `getShuttingDown()` to `ExitHandler` as the single source of truth
- Services receive ExitHandler reference instead of each implementing their own copy

### 3d. Consolidate shutdown polling
- BaseScraper.waitForDownloads() and SyncScraper both poll `getShuttingDown()` with setTimeout
- Extract shared `waitForCondition(conditionFn, pollMs)` utility
