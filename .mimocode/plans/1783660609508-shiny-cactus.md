## Phase 3: DRY & Consistency

### 3.1 Shared `addUnique` utility
Both `ApiScraper.addUnique()` (static) and `UrlGenerator`'s inline `add()` do append-if-not-present.

Add to `src/utils/array.ts`:
```typescript
export function addUnique(arr: string[], value: string): void {
  if (value && !arr.includes(value)) arr.push(value);
}
```
Update: `ApiScraper`, `UrlGenerator`, `MediaParser` to use this shared utility. Remove `ApiScraper.addUnique` static method.

### 3.2 Rename ExportService.export → exportData
Avoids potential confusion with the `export` keyword. Update `AppService.exportArticles` to call `this.exportService.exportData(...)`.

### 3.3 Extract backoff helper
`NetworkService.fetch` has identical `setTimeout(resolve, 1000 * (attempt + 1))` in both try and catch blocks (lines 109, 132).

Extract:
```typescript
private backoff(attempt: number): Promise<void> {
  return new Promise(resolve => setTimeout(resolve, 1000 * (attempt + 1)));
}
```

### 3.4 Extract migration helper
`DatabaseService.init()` has copy-pasted try/catch blocks for column migrations (lines 70-85).

Extract:
```typescript
private tryAddColumn(sql: string, label: string): void {
  try {
    this.db.run(sql);
  } catch (error) {
    const msg = error instanceof Error ? error.message : String(error);
    if (!msg.includes("duplicate column name")) {
      console.error(`Migration failed for column '${label}': ${msg}`);
    }
  }
}
```
